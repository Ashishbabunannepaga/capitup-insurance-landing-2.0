# CapitUp Streamlit Insurance Landing

Mobile-first public landing page for the CapitUp QR campaign.

Flow:
QR → Streamlit landing page → Health / Term Life / Motor → Tally.

Tally forms:
- Health: https://tally.so/r/KYbbbD
- Term Life: https://tally.so/r/A7Z1GD
- Motor: https://tally.so/r/PdKVJb

Run locally:
streamlit run app.py

Deploy:
- Streamlit Community Cloud: connect this folder/repository and set main file to `app.py`.
